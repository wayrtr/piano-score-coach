# Responsive workspace acceptance — 2026-10-02

## Scope

The original Next.js desktop/local app retains all existing MusicXML/MXL, image/PDF, Audiveris, storage, lifecycle, audio-library and music-theory code. This change adapts the working surface, not the score's musical content.

- Removes the 920 px workspace minimum and splits the phone header into two rows
- Provides 44 px note-navigation controls using the existing navigation algorithm; exact pitch, staff and octave semantics are unchanged
- Keeps score and instrument results independently scrollable, including dense multi-row key groups
- Uses side-by-side score/results in short landscape screens and retains the desktop layout
- Preserves liquid-glass components, opaque music paper, dark mode, reduced motion/transparency and safe-area padding
- Keeps complete octave labels on highlighted black keys

The displayed piano keys remain an instrument-position reference, as before; this does not add a playable keyboard or remove a pre-existing keyboard performance mode.

## Online deployment distinction

The separately published private ChatGPT Site is explicitly MusicXML/XML/MXL-only. It uses persistent platform D1 metadata and R2 score files; no personal scores or local SQLite data are migrated automatically. PDF/image recognition remains in this local app. Online source and hosting repository are separate from this GitHub remote so hosting helpers cannot overwrite the local app's Git history.
